# Blueprint capability matrix

What a project generated by `scripts/create-project` contains. Two independent choices:
- an **architecture profile** (`--profile`), which selects infrastructure modules;
- an **auth profile** (`--auth`, plus `--organizations`, `--admin` and `--cedar`), which selects
  identity and tenancy.

Optional modules are **cargo features plus configuration plus compose services**. An unselected
module:
- is not compiled into the binaries;
- is not started by `./dev up`, and has no CI service;
- has no enabled configuration and no validation command.

`scripts/validate-generated` checks the binaries, the running services, the configuration, and
the running server's own `configuration` log line. Enabling a module later takes five documented
steps: [docs/MODULES.md](MODULES.md).

## Auth profiles

Single-tenant profiles (basic, consumer) still give every user a personal workspace, so data is
always tenant-scoped.
