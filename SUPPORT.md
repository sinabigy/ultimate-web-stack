# Getting help

| need | where |
|---|---|
| "How do I…?", setup trouble, design questions | **GitHub Discussions → Q&A**; check [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md) and [docs/FAQ.md](docs/FAQ.md) first |
| ideas, show-and-tell, what you built with it | GitHub Discussions → Ideas / Show and tell |
| a reproducible bug | an issue (**Bug report** template), with the failing command and output |
| a security vulnerability | privately, per [SECURITY.md](SECURITY.md) |
| benchmark results from your hardware | an issue (**Benchmark result** template) |

This is a community project with no guaranteed response times. Issues that include
`./dev doctor` output and the exact failing command get answered fastest.

## Supporting the project
If this project saved you time, ⭐ star the repository: it helps other developers find it. If you
want to support continued development and regression testing, use the **Sponsor** button on the
repository.
